# Organizador PC

App de escritorio para **Windows** que organiza tu escritorio, reúne tus juegos y programas en una biblioteca y optimiza el PC.

## Descargar y usar

1. Pulsa el botón verde **Code → Download ZIP**.
   **Descomprímelo** (clic derecho → *Extraer todo…*). No ejecutes nada desde dentro del ZIP.
2. Instala [Python 3.10 o superior](https://www.python.org/downloads/) marcando **"Add python.exe to PATH"**.
3. Dentro de la carpeta extraída, doble clic en **`Iniciar.bat`** (la primera vez instala las dependencias).
4. Opcional: **`Crear_EXE.bat`** genera `dist\OrganizadorPC.exe`, que funciona sin Python.

## Funciones

- **🎮 Biblioteca:** detecta juegos de Steam (con portada), Epic Games y GOG, accesos del escritorio y menú Inicio. Buscador, favoritos, categorías y orden por uso.
- **🗂 Organizar escritorio:** agrupa todo en carpetas (Juegos, Programas, Documentos, Imágenes, Vídeos…) con vista previa y botón **Deshacer**.
- **⚡ Optimizar PC:** limpieza de temporales y cachés (navegadores, Discord, Spotify, Steam/Epic, shaders, Windows Update, papelera…), programas de inicio, procesos que más RAM usan y herramientas (DNS, plan de energía, SFC, DISM…).
- **⚙ Ajustes:** tema oscuro/claro, iniciar con Windows y organización automática.

Los datos se guardan en `%APPDATA%\OrganizadorPC`.
